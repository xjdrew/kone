- Web：16 项 Bun 核心测试约 0.4 秒、两项 Node 门禁契约约 0.06 秒；21 项浏览器用例约 19 秒，覆盖精确规则与撤销、策略冲突、原始窗口钻取、草稿、会话撤销、双语焦点、320 px 与 200% CSS 缩放，新增远程监听首次密码与 HTTP/HTTPS、任意目标诊断逐项反馈与展开；并使用真实 Go 服务保存/重启。
- 任务脚本 52 项、发布 23 项、数据 5 项；构建资产验证 LF/CRLF 一致性。浏览器测试必须先执行 `just ci web-build`，避免验证旧内嵌资源。
- 在本次主机上，Telegram `149.154.167.50:443` 直连 5 秒超时，经 `127.0.0.1:7078` HTTP CONNECT 成功（371 ms），未发送 TLS；精确 `/32 + tcp + 443` 规则模拟命中 Local HTTP。
- Google `google.com:443` 直连 5 秒超时，经同一代理完成目标 TLS（857 ms）。两项均是显式诊断，测试期间代理保持暂停，不作为 TUN 接管证明。
- 本机没有 C 编译器，Go 非 race 全包测试与 vet 可执行；race、Windows/macOS 原生能力和新增 Linux 全局策略三栈用例由 PR CI 验证。手机系统证书、屏幕键盘、物理 IPv6、特殊 VPN/Linux 策略路由、长期负载仍属于部署验收。
