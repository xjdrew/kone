# 桌面使用与排障

Windows 双击 `kone.exe`，macOS 打开 `Kone.app`，程序默认只显示托盘或菜单栏图标，不弹终端，也不自动打开浏览器。点击图标中的“打开管理”进入 Web 界面。打开程序时接管保持暂停；关闭浏览器不等于停止接管，暂停或退出请使用管理页面或托盘菜单。

终端操作使用 Windows 的 `kone-cli.exe`、macOS 的 `kone-cli`。Linux 保留 `kone` 的 CLI 和网关用法。CLI 参数见 [使用说明](usage.md#toml-and-file-mode)，开发构建见 [开发说明](development.md)。

## 首次启用接管

Web 管理使用用户目录下的独立 profile，首次启动不会读取项目根目录的 `config.toml`，也不会导入终端代理环境。修改该 TOML 不会改变当前管理界面的设置；需要时请在界面中显式导入配置，或用 CLI 的 `-config` 文件模式运行。

首次从本机托盘打开后，先设置管理密码并再次确认。密码至少 8 个字符，UTF-8 长度不超过 128 字节；之后使用密码登录，托盘链接不能绕过密码。直接访问尚未初始化的地址不会取得设置权限，需从本机托盘重新打开。手机可继续使用所有者在登录后创建的短期配对代码。

密码以随机盐加 Argon2id 哈希保存在 profile 的 `auth.json`，不进入 TOML 导出或日志；认证与具体参数见 [Argon2 官方说明](https://pkg.go.dev/golang.org/x/crypto/argon2)。忘记密码时，退出 KONE、备份 profile 并将 `auth.json` 移出该目录，再从本机托盘重新设置；保留 `settings.json` 即可保留代理和规则。能修改 profile 的本机账户属于主机信任边界。

1. 首次创建的管理配置准备好 TUN 入站、默认规则和系统 DNS 发现，接管仍保持暂停。已有配置保持原样；需要调整时，在“入站”查看摘要并选择**编辑入站**。
2. 在“出站”添加代理，在编辑对话框中**测试连接**，查看目标、阶段和结果后保存。列表显示最近测试的状态与时间，过期结果不会继续标成正常。测试仅验证所列目标，不代表所有业务都可用。规则默认保持直连；需要代理的目标请在“规则”显式指定出站，不会因添加代理自动改变已有策略。
3. 点击**启用接管**，先检查集中列出的未就绪项，按引导完成设置后重试。没有代理出站时，必须明确确认**仅直连**。Windows 按需请求 UAC，macOS 请求网络助手授权；允许授权后仍要等待实际启动结果。顶部显示“正在接管”才表示已就绪，保存设置和同意授权都不等于已经启用。

如果出现“请先启用 TUN 入站”或 `enable the TUN inbound before starting capture`，回到第一步启用并保存即可，不需要重新安装驱动或反复启动程序。

## 查看与编辑

各页先展示状态、列表或记录；点击添加、编辑、详情等操作后才打开相应对话框。取消编辑不会保存，保存成功后返回列表并刷新。出站列表可查看最近测试状态、测试连接、编辑、删除和查看详情；内置 `direct`、`reject` 的行为不需要编辑。

接管运行中，TUN、协议栈、捕获范围和其他需要重启的配置被锁定；暂停接管后再修改。规则和出站保存后热应用到新连接，已有连接保留原快照。界面区分已保存与已生效；应用失败时保留原运行配置并显示原因，可修正后重试。

网关部署还要配置 LAN 客户端的网关、DNS、转发和返回路由，见 [Raspberry Pi 网关指南](guides/how-to-use-with-raspberry-pi.md)。桌面界面不会自动接管其他机器。

## 查看失败原因

托盘启用或暂停失败时会打开诊断页；GUI 还显示原生提示。管理服务保留，修正设置后可以重试。操作成功不会强制打开浏览器或打断日常使用。

在“诊断”的“运行日志”中按最低级别和来源筛选，查看启动、权限助手、连接及清理错误。日志是当前进程的近期、有容量上限的脱敏记录；旧记录可能被淘汰，退出后不作为持久审计保存。权限助手未启动时没有助手日志属于正常情况。

“设置”中的日志级别和格式继续控制采集；保存后按界面提示应用或重启生效。诊断页的最低级别只过滤现有记录，选择 DEBUG 不会补回此前没有采集的调试日志。

授权或启动期间，流量、DNS 或助手数据可能暂不可用；页面会独立提示数据降级，并注明上次快照。只要管理连接仍正常，仍可查看配置、启动结果和日志，不应把数据缺失当成管理进程退出。若管理连接本身中断，先确认托盘程序仍在，再从托盘重新打开管理。桌面启动失败会显示原生提示，需要终端排查时使用 `kone-cli`。
