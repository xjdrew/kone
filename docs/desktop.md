# 桌面使用与排障

Windows 双击 `kone.exe`，macOS 打开 `Kone.app`，程序默认只显示托盘或菜单栏图标，不弹终端，也不自动打开浏览器。点击图标中的“打开管理”进入 Web 界面。打开程序时接管保持暂停；关闭浏览器不等于停止接管，暂停或退出请使用管理页面或托盘菜单。

Windows 托盘右键菜单使用品牌和操作图标，并将打开管理、接管控制、诊断与退出分组；启动和暂停是否可用取决于当前接管状态。

终端操作使用 Windows 的 `kone-cli.exe`、macOS 的 `kone-cli`。Linux 保留 `kone` 的 CLI 和网关用法。CLI 参数见 [使用说明](usage.md#toml-and-file-mode)，开发构建见 [开发说明](development.md)。

## 首次启用接管

Web 管理使用用户目录下的独立 profile，首次启动不会读取项目根目录的 `config.toml`，也不会导入终端代理环境。修改该 TOML 不会改变当前管理界面的设置；需要时请在界面中显式导入配置，或用 CLI 的 `-config` 文件模式运行。

首次从本机托盘打开后，先设置管理密码并再次确认。密码至少 8 个字符，UTF-8 长度不超过 128 字节；之后使用密码登录，托盘链接不能绕过密码。直接访问尚未初始化的地址不会取得设置权限，需从本机托盘重新打开。手机可继续使用所有者在登录后创建的短期配对代码。

登录、首次设置密码与配对授权使用独立的全屏页面。确认管理会话前及退出或会话失效后，主界面的导航、状态栏和操作控件均隐藏，登录成功后才显示。

密码以随机盐加 Argon2id 哈希保存在 profile 的 `auth.json`，不进入 TOML 导出或日志。当前使用 19 MiB 内存、2 轮、1 个并行通道，采用 [OWASP 的 Argon2id 基准参数](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#argon2id) 降低交互等待；算法见 [Argon2 官方说明](https://pkg.go.dev/golang.org/x/crypto/argon2)。旧版认证文件不兼容，也不会自动迁移或删除：升级前退出 KONE、备份 profile 并将 `auth.json` 移出该目录，再从本机托盘重新设置。忘记密码也可按相同步骤操作；保留 `settings.json` 即可保留代理和规则。能修改 profile 的本机账户属于主机信任边界。

1. 首次创建的管理配置准备好 TUN 入站、默认规则和系统 DNS 发现，接管仍保持暂停。已有配置保持原样；需要调整时，在“入站”查看摘要并选择**编辑入站**。
2. 在“出站”添加代理，选择协议并填写服务器地址、端口及所需认证信息；名称自动生成，也可以修改。保存会自动校验，并在成功后建议**测试连接**；测试由你点击发起，列表下方会展开详情并持续更新过程、连接状态和延迟。规则默认保持直连；需要代理的目标请在“规则”显式指定出站，不会因添加代理自动改变已有策略。
3. 点击**启用接管**即可启动，程序自动预检并处理上次可安全清理的残留。首次仅使用直连规则时，只需确认一次直连模式。Windows 按需请求 UAC，macOS 请求网络助手授权；允许授权后仍要等待实际启动结果。顶部显示“正在接管”才表示已就绪，保存设置和同意授权都不等于已经启用。

如果出现“请先启用 TUN 入站”或 `enable the TUN inbound before starting capture`，回到第一步启用并保存即可，不需要重新安装驱动或反复启动程序。

## 查看与编辑

各页先展示状态、列表或记录；点击添加或编辑后再进入紧凑表单，主要操作统一为**保存**和**取消**。保存自动完成校验，必要时显示生效影响；测试和高级配置按需展开。入站与 DNS 优先显示常用设置，规则优先显示匹配条件与出站，其他选项放在高级区域。取消不会保存，成功后返回列表或设置页面。

规则页使用**添加规则**，按精确域名、域名后缀、关键词、IP 网段或 GeoIP 国家提供对应输入。手动添加域名规则默认匹配 TCP、UDP 和全部端口；高级匹配条件可缩小协议、端口及有效期。由已观察连接创建的快捷规则仍保留该连接的协议与端口。GeoIP 列出国家名称与代码，IP 网段需要地址与前缀长度，域名匹配不使用 `*` 通配符。

**最终规则 FINAL**单独固定在底部，只能编辑兜底出站，不能新增、删除或排序；没有显式 FINAL 时显示内置直连，编辑保存后才写入配置。普通规则的匹配方式不包含 FINAL。旧配置中带协议或端口限制的 FINAL 会提示原范围，必须明确确认后才改为覆盖所有未命中流量。模拟匹配显示具体规则及出站，未匹配时显示 FINAL；计算只使用输入目标和已保存规则，不解析 DNS，也不代表连通性测试。

需要接管的域名在启用 IPv6 时同时生成 Fake-IPv6；未启用 IPv6 时，其 AAAA 查询返回空结果，阻止客户端使用真实 IPv6 绕过该域名策略。直连域名和代理端点保持真实解析。规则变化作用于重新解析后建立的新连接，已有连接和客户端 DNS 缓存不会被强制清除。

出站支持 HTTP、HTTPS CONNECT、SOCKS5 和 Shadowsocks。填写完整认证信息即可替换，已有认证两项留空会保留，清除需明确操作；修改代理地址或协议时需要重新填写或清除认证，密码不会回显。编辑时可展开连接测试，测试草稿不会保存设置；保存后也会建议测试，点击后才会连接所列目标。详情分别显示代理端点连接与协议检查，连接延迟来自实际 TCP 建连，包含端点域名解析；端点可达不等于代理握手、目标 TLS 或 UDP 已可用。结果注明测试目标、时间及过期状态，修改地址或认证后需要重新测试。

出站列表先显示可只读查看的内置 `direct`、`reject`，再显示代理。每个出站标明已保存规则的引用数量，包含显式 FINAL；内置默认直连不算配置引用，会在查看时单独说明。已到期规则仍保留其配置引用，引用详情会标明到期状态。

UDP 回退入口在显式测试确认当前出站不支持 UDP 后才展示，可选直连或拒绝。管理页新建出站默认选择直连回退，已有出站保留已保存策略。没有实际 UDP 回包证据时显示未验证，不把 TCP 测试成功当作 UDP 已通；协议本身不提供 UDP 时也会说明证据。测试不代表所有应用业务都可用，内置 `direct`、`reject` 不需要编辑。

界面自动更新状态和已保存配置，无需手动刷新。“设置”采用分组菜单列表，参考 iOS 通用设置的浏览方式：**关于 KONE**放在最上方，日志、GeoIP、访问与安全、数据和维护分别归组。点击项目进入独立的二级页面，页面顶部可返回设置；在表单中修改并保存，未保存离开会先提示。

**重置所有配置**与**退出登录**位于设置列表底部。修改管理密码需先验证当前密码，成功后保留本页登录，其他登录与待用配对代码失效。重置只允许从本机管理会话执行，要求接管已暂停；可安全处理的残留会自动清理。确认后将入站、代理、规则、DNS、日志、GeoIP 与局域网访问恢复默认，撤销远程登录和配对代码，保留管理密码与本机登录。默认 TUN 入口已启用，但接管保持暂停，重新启用时仍需确认直连模式。重置前可导出脱敏配置；导出不含代理密码。重置会保留历史备份，撤销仅能恢复曾成功启用的有效配置，不能保证找回尚未启用的修改。

接管运行中，TUN、协议栈、捕获范围和其他需要重启的配置被锁定；暂停接管后再修改。规则和出站保存后热应用到新连接，已有连接保留原快照。界面区分已保存与已生效；应用失败时保留原运行配置并显示原因，可修正后重试。

网关部署还要配置 LAN 客户端的网关、DNS、转发和返回路由，见 [Raspberry Pi 网关指南](guides/how-to-use-with-raspberry-pi.md)。桌面界面不会自动接管其他机器。

## 查看失败原因

尚未运行接管时显示“尚未接管”。启动时自动检查并清理可验证安全的接管记录，正常暂停和退出也自动恢复网络。Windows 异常遗留的机器 DNS 规则仍需在本机“设置 → 网络维护 → 手动维护”明确确认并授权恢复；自动清理不会代替这一步。无法确认归属的设备或被外部修改的规则不会被删除，启动失败会给出简短提示；过程与具体原因记录在运行日志中。

托盘启用或暂停失败时会打开诊断页；GUI 还显示原生提示。管理服务保留，修正设置后可以重试。操作成功不会强制打开浏览器或打断日常使用。

管理服务启动后就会记录日志，无需先启用接管。在“诊断”的“运行日志”中按最低级别和来源筛选，查看管理就绪、预检、自动清理、权限助手、接管启停及失败结果。默认 INFO 和全部来源可查看正常过程；暂停接管后仍保留本次进程的历史。日志有容量上限并经过脱敏；旧记录可能被淘汰，退出后不作为持久审计保存。权限助手未启动时没有助手日志属于正常情况。

日志主体使用紧凑表格，支持时间范围、分页和分色级别；自动刷新保留阅读位置及展开字段。真实出站连接失败会作为 ERROR 出现在默认 INFO 视图。向前翻页或查看字段时，新记录先提示，点击回到最新后再展示，详见 [诊断与日志](diagnostics.md)。

“设置”中的日志级别和格式控制底层引擎诊断信息；关键管理与启停事件始终保留在运行日志中。保存后按界面提示应用或重启生效。诊断页的最低级别只过滤现有记录，选择 DEBUG 不会补回此前没有采集的调试日志。

授权或启动期间，流量、DNS 或助手数据可能暂不可用；页面会独立提示数据降级，并注明上次快照。只要管理连接仍正常，仍可查看配置、启动结果和日志，不应把数据缺失当成管理进程退出。若管理连接本身中断，先确认托盘程序仍在，再从托盘重新打开管理。桌面启动失败会显示原生提示；旧认证格式会直接说明移出 `auth.json`、保留 `settings.json` 的重设步骤。其他启动原因需要终端排查时使用 `kone-cli`。
