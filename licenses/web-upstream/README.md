# Supplemental Web license

`react-remove-scroll-bar@2.3.8` declares MIT but its npm archive omits the license file. `react-remove-scroll-bar-2.3.8.txt` preserves the upstream MIT notice from [the author's repository at 8ca9ba5](https://github.com/theKashey/react-remove-scroll-bar/blob/8ca9ba5ea52de03308fe8ced94f7b159a44d28ff/LICENSE), retrieved 2026-11-07. The npm `gitHead` does not resolve in that repository; this source is identified explicitly rather than attributed to that unavailable commit.

`just ci web-build` collects installed production dependency notices into `../web-third-party.txt`; `just ci web-check` verifies the result. The application package carries the notices in `licenses/`. Development-only tools are not bundled into the application.
